Bukti Belajar P1

1. Konsep Dasar Pemrograman Web

Pemrograman web adalah kegiatan membuat sebuah website atau aplikasi yang dapat diakses melalui internet menggunakan browser.

2.Arsitektur Klien-Peladen

Arsitektur klien-peladen atau client-server adalah cara kerja antara komputer pengguna dan server. Client biasanya berupa browser yang digunakan untuk mengakses website, sedangkan server bertugas menerima permintaan dari client dan memberikan hasilnya.

3.HTTP Request dan Response

HTTP Request adalah permintaan yang dikirim oleh client kepada server ketika kita melakukan suatu aktivitas di website. Misalnya, saat membuka halaman atau mengirimkan data melalui formulir. Setelah menerima permintaan tersebut, server akan memprosesnya dan mengirimkan HTTP Response sebagai balasan.

4.HTML, CSS, JavaScript, PHP, dan MySQL

HTML digunakan untuk membuat struktur sebuah halaman web, seperti judul, teks, gambar, tabel, dan tombol. 

CSS digunakan untuk mengatur tampilan halaman agar lebih rapi dan menarik, seperti warna, ukuran tulisan, dan tata letak.

JavaScript digunakan untuk membuat website lebih interaktif, misalnya memberikan respons ketika tombol diklik.

PHP digunakan untuk mengolah data dan menjalankan proses di sisi server.

MySQL digunakan untuk menyimpan dan mengelola data dalam database. Kelima teknologi tersebut memiliki fungsi yang berbeda, tetapi dapat digunakan bersama dalam pembuatan sebuah website.

5.Hubungan Antarteknologi

HTML, CSS, JavaScript, PHP, dan MySQL saling berhubungan dalam pembuatan aplikasi web. HTML menjadi dasar untuk membuat struktur halaman, kemudian CSS mengatur tampilannya dan JavaScript menambahkan interaksi.
